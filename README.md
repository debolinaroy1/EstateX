# 🏡 EstateX – Premium Real Estate Platform

EstateX is a modern, responsive real estate frontend that provides a premium property browsing experience with elegant UI, smooth animations, dark mode support, and interactive components. The project focuses on creating a clean, user-friendly interface for exploring residential and commercial properties.

## ✨ Features

- Modern and responsive UI

- Featured real estate agents
- Mortgage calculator
- Testimonials carousel
- Blog section
- FAQ section
- Contact page
- Dark / Light mode
- Smooth scrolling
- Interactive animations
- Mobile-first responsive design
- Cookie consent banner
- Floating WhatsApp contact button
- Scroll progress indicator
- Back-to-top button
